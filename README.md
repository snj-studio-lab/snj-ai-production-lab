# S&J Studio AI Production Lab

S&J Studio AI Production Lab is a public record of how a solo creator experiments with AI-assisted cinematic video production.

This repository collects production notes, postmortems, templates, and workflow lessons from real AI video projects.

It is not a showcase of perfect outputs.

It is a working lab: a place to document what broke, what changed, and what can be learned from the process.

## What this is

This is a public learning archive for AI-assisted video production.

The focus is on:

- AI video workflow design
- cinematic storyboard-to-video production
- prompt and reference-image failure analysis
- solo studio operations
- longform video production systems
- production checklists and templates
- postmortems from real channel work

The goal is to make the process useful, not to make the creator look flawless.

## Why this exists

AI video production is often presented as if it only takes a good prompt and a good tool.

In real production, the work breaks in many places:

- a script can work on paper but fail on screen
- a reference image can protect identity in one cut and create duplication in another
- a storyboard can guide continuity or accidentally become the generated layout
- a production rule can prevent one mistake while creating a new one
- a scene can pass every internal check and still fail as entertainment

This repository documents those failures and the production rules that came out of them.

## What I share here

- generalized production postmortems
- workflow notes
- public templates
- prompt structure lessons
- production gate checklists
- before/after style problem analysis
- lessons from building AI-assisted cinematic videos as a solo creator

## What I do not share here

This repository does not include unreleased scripts, private character assets, or confidential production materials.

The public focus is on transferable lessons, not private IP.
