# S&J Studio AI Production Lab

Public notes, templates, and postmortems from S&J Studio — a solo AI video production lab testing cinematic AI filmmaking workflows in real YouTube channel operations.

S&J Studio Lab is not a showcase of perfect outputs. It is a public record of where AI-assisted video production breaks, how the workflow is repaired, and what a solo creator can learn from the process.

## What this is

This repository documents the practical production system behind building AI-assisted cinematic videos as a solo creator.

The focus is not on isolated prompts. The focus is on the full production chain:

- concept development
- script and scene structure
- cut-based planning
- reference image control
- storyboard prompt design
- AI video generation
- subtitle cleanup
- upload packaging
- production review
- failure analysis

The goal is to turn real production mistakes into reusable public knowledge.

## What this is not

This is not a get-rich-quick AI prompt collection.

This is not a full release of private scripts, characters, channel strategy, or internal production engines.

This is not a finished course.

This is not a claim that AI video production is easy, automatic, or solved.

## Core themes

## Why this lab exists

AI video production often looks simple from the outside.

A creator writes a prompt, generates an image, turns it into video, and uploads the result.

In real production, the process is rarely that clean.

A script can look good but fail as video.  
A storyboard can clarify the scene for the creator but confuse the video model.  
A reference image can protect character identity in one cut and duplicate the same character in another.  
A production rule can prevent one error while creating a new one somewhere else.

S&J Studio Lab exists to document those failures in public, without exposing private scripts, character assets, or internal production documents.

## Public / private boundary

This repository only includes generalized public material.

Included:

- production postmortems
- generalized workflow notes
- public templates
- prompt structure lessons
- before/after style problem analysis
- non-sensitive production principles
- anonymized or simplified examples

Not included:

- full private scripts
- original character asset files
- unreleased IP documents
- complete internal STEP engines
- detailed revenue data
- private conversations
- unreleased channel strategy
- sensitive personal information
